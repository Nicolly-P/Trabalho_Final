# Santa Glória

> Um jogo de terror com interações 3D.

## 📌 Sobre o projeto

A **Santa Glória** é um projeto desenvolvido com o objetivo de trazer inovação à comunidade trazendo uma mistura dos jogos 2D (duas dimensões) com o 3D (terceira dimensão) e a valorização de jogos nacionais que valorizem a história do próprio país.

A aplicação permite que o usuário se aventure na história de Amélia, que enfrenta o desaparecimento de sua irmã, porém numa noite recebe uma ligação contando que Yelena está presa no “Hospital Santa Glória”, o qual agora vira seu objetivo principal: Ir nesse lugar para salvá-la.
 

## 🎯 Objetivos

- Inovar o mercado de jogos.
- Aplicar conhecimentos do curso técnico Desenvolvimento de Sistemas.
- Desenvolver habilidades de interação entre elementos 2D e 3D.
- Resolver a falta de conhecimento acerca da história brasileira.

## 💻 Tecnologias utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento:

- **Linguagens:** Javascript, HTML e CSS.
- **Ferramentas:** Visual Studio Code, Git, GitHub, Pinterest, Documento, Ibispaint e Canva.
